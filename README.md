# Чат-бот «Менеджер задач» для мессенджера MAX в Yandex Cloud (Free Tier)

Чат-бот предназначен для ведения задач отдельно в каждом чате мессенджера MAX.
Развёртывается в бессрочном **бесплатном тарифе (Free Tier) Yandex Cloud** с использованием связки **Serverless Cloud Functions + YDB Serverless**.

---

## 🎯 Возможности

- **Изоляция по чатам:** задачи каждого чата строго независимы.
- **Права администраторов:** добавлять задачи, отмечать их выполненными и очищать базу могут администраторы чата.
- **Прикрепление скриншотов:** к любой задаче можно прикрепить один или несколько скриншотов (как при создании, так и командой `/attach`).
- **Удобная нумерация:** задачи в каждом чате нумеруются по порядку `#1`, `#2`, `#3` (без длинных UUID).
- **Очистка базы данных:** команда `/clear_done` удаляет завершённые задачи из базы данных, не захламляя хранилище.

---

## 📋 Команды бота в чате

| Команда | Описание |
|---|---|
| `/task <текст>` | Создать новую задачу (прикрепите фото или скриншоты прямо к сообщению). |
| `/tasks` или `/список` | Список всех открытых задач текущего чата. |
| `/info <номер>` | Посмотреть подробности задачи и все прикрепленные скриншоты. |
| `/done <номер>` | Отметить задачу выполненной (доступно админам). |
| `/attach <номер>` | Добавить дополнительные скриншоты к существующей задаче. |
| `/clear_done` | Удалить из базы данных все выполненные задачи чата. |
| `/help` | Справка по командам. |

## ☁️ Архитектура и Free Tier в Yandex Cloud

В Yandex Cloud постоянная работа виртуальной машины (Compute Cloud) стоит денег после окончания 60-дневного пробного периода.
Поэтому бот построен на архитектуре **Serverless**:

1. **Yandex Cloud Functions (Python 3.11/3.12):**
   - Получает вебхуки от мессенджера MAX по HTTPS.
   - **Лимиты Free Tier:** 1 000 000 вызовов в месяц и 10 ГБ-часов памяти — **бесплатно навсегда**.
2. **Yandex Database (YDB) Serverless:**
   - Хранит таблицы `tasks` и `chat_counters`.
   - **Лимиты Free Tier:** до 1 ГБ данных и 1 000 000 Request Units в месяц — **бесплатно навсегда**.

Итого: **0 ₽ в месяц**.

## 🚀 Пошаговое руководство по развертыванию

### Шаг 1. Создание базы данных YDB в Yandex Cloud
1. Откройте [Консоль Yandex Cloud](https://console.yandex.cloud/).
2. Перейдите в раздел **Managed Service for YDB**.
3. Нажмите **Создать базу данных**, выберите тип **Serverless**, задайте имя (например, `max-task-db`).
4. После создания базы скопируйте из ее свойств:
   - **Endpoint** (например: `grpcs://ydb.serverless.yandexcloud.net:2135`)
   - **Путь к базе данных (Database)** (например: `/ru-central1/b1g.../etn...`)
5. В левом меню перейдите в **Навигация** -> **SQL-запрос**, вставьте содержимое файла `schema.sql` и нажмите **Выполнить**. Таблицы созданы!

### Шаг 2. Создание сервисного аккаунта
1. В консоли облака перейдите в **Сервисные аккаунты**.
2. Создайте аккаунт (например, `max-bot-sa`).
3. Назначьте ему роль: `ydb.editor` (для чтения и записи в YDB).

### Шаг 3. Создание Yandex Cloud Function
1. Перейдите в раздел **Cloud Functions** -> **Создать функцию** (например, `max-task-bot`).
2. В настройках функции:
   - Среда выполнения: `Python 3.11` или `Python 3.12`.
   - Точка входа: `index.handler`.
   - Сервисный аккаунт: выберите созданный на шаге 2 (`max-bot-sa`).
   - Память: `128 МБ` (достаточно для минимального расхода квот).
   - Таймаут: `5 секунд`.
3. Добавьте переменные окружения:
   - `MAX_BOT_TOKEN` — токен вашего бота в мессенджере MAX.
   - `MAX_API_BASE_URL` — базовый URL API мессенджера MAX (по умолчанию `https://api.max.chat/v1`).
   - `YDB_ENDPOINT` — эндпоинт YDB из Шага 1.
   - `YDB_DATABASE` — путь к базе данных YDB из Шага 1.
4. Загрузите код:
   - Запакуйте файлы `index.py`, `bot.py`, `db.py`, `models.py`, `max_api.py`, `config.py`, `requirements.txt` в `.zip` архив и загрузите его (или скопируйте файлы через редактор кода в веб-интерфейсе).
5. Нажмите **Сохранить изменения**.
6. Во вкладке **Обзор** включите переключатель **Публичная функция**.
7. Скопируйте **Ссылку для вызова функции** (например: `https://functions.yandexcloud.net/d4e...`).

### Шаг 4. Настройка вебхука в мессенджере MAX
Укажите полученную ссылку на Cloud Function в качестве Webhook URL в настройках бота мессенджера MAX.
Бот готов к работе!

Для проверки логики без облака можно запустить:
